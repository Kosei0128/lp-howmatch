# LP Howmatch

Web production estimate simulator for landing pages and small websites.

LP Howmatch helps users quickly understand a rough production cost by selecting website requirements such as page volume, design scope, responsive support, and optional features.

## Overview

This project was built as a practical tool for web production consultations.  
It is designed to make pricing easier to explain and easier for clients to understand before a detailed quote is created.

## Features

- Estimate simulation for landing page / website production
- Requirement-based price calculation
- Simple UI for non-technical users
- Public deployment on Vercel
- Built as part of a portfolio and client communication workflow

## Tech Stack

- Next.js
- TypeScript
- React
- Vercel
